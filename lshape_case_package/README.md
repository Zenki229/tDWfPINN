# L-shaped time-fractional diffusion-wave reference package

This package contains code, figures, and manuscript-ready text for an L-shaped-domain benchmark for the revised tDWfPINNs paper.

## Motivation

The case is designed to address reviewer concerns about multidimensional tests, irregular geometry, and comparison against a strong reference numerical method.  The benchmark uses a nonconvex L-shaped domain and a high-resolution reference solution generated by modal finite differences or finite elements.

## Domain

The standard L-shaped domain is

\[
\Omega_L = [-1,1]^2 \setminus [0,1]^2 .
\]

## Model problem

A reference model is

\[
\partial_t^\alpha u - \nabla\cdot(a(x,y)\nabla u)=0,
\qquad (t,x,y)\in(0,T]\times\Omega_L,
\]
with homogeneous Dirichlet boundary conditions and initial data
\[
u(0,x,y)=g(x,y),\qquad \partial_t u(0,x,y)=b(x,y),
\]
where \(1<\alpha<2\).  The code examples use either a homogeneous coefficient in the finite-difference preview or a heterogeneous coefficient in the scikit-fem version.

## Contents

- `code/lshape_fd_reference_and_gif.py`  
  Self-contained finite-difference eigenmode reference and GIF generator.  This was used to create the included figures.

- `code/lshape_fractional_dw_fem_reference.py`  
  Higher-fidelity scikit-fem FEM eigenmode reference generator using the built-in L-shaped mesh.

- `figures/lshape_fd_reference_profile_t05.png`  
  Heatmap at \(t=0.5\).

- `figures/lshape_fd_reference_surface_t05.png`  
  3D surface plot at \(t=0.5\).

- `figures/lshape_fd_reference_evolution_slice_xminus05.png`  
  Time-evolution surface on the slice \(x=-0.5\).

- `figures/lshape_heatmap_evolution.gif`  
  Heatmap animation over \(t\in[0,1]\).

- `tex/lshape_case_description.tex`  
  A manuscript-ready LaTeX description.

## How to run

Install dependencies:

```bash
pip install -r requirements.txt
```

Generate the self-contained finite-difference reference and GIF:

```bash
python code/lshape_fd_reference_and_gif.py
```

Generate the higher-fidelity scikit-fem reference:

```bash
python code/lshape_fractional_dw_fem_reference.py
```

The scikit-fem script saves snapshots and reference data for later comparison with a PINN prediction.

## Suggested use in the manuscript

Use the circular-hole manufactured example for clean exact-error tables, and use this L-shaped case as a more visually compelling complex-geometry reference-solver comparison.  This avoids forcing an artificial analytic solution on a nonconvex polygonal domain.
